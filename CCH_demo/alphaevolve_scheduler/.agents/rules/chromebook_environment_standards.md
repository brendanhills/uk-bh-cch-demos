# Chromebook (ChromeOS) Environment Standards

- **Hardware & OS Context:** The user operates exclusively on a **Chromebook (ChromeOS)**.
- **Keyboard Shortcuts & Keybindings:**
  - Whenever providing instructions for browser refresh, developer tools, terminal commands, or IDE actions, **always prioritize Chromebook / ChromeOS shortcuts** as the primary option.
  - **Hard Refresh Shortcut:** Always provide `Ctrl + Shift + r` (or holding `Shift` while clicking the browser reload button `↻`).
  - Do not assume standard Windows or macOS keyboard layouts without noting Chromebook equivalents.
