# Product Guidelines: Loan Approval Agent Demo\n\n## Design Principles\n- **Trust through Transparency**: The demo MUST prioritize the **Agent Thought Process (Trace)** and **Live Audit Logs**. The audience should never wonder "what is the AI doing?"; every tool call and reasoning step must be visible.\n- **Professional Trust**: The UI aesthetic will follow a **Clean Financial White** theme—utilizing a professional, minimalist layout that evokes the reliability of a high-end banking application.\n- **Narrative Clarity**: While the product goal is speed, the demo pace will emphasize **Step-by-Step Clarity**. Use slight delays or clear visual transitions to ensure the audience can follow the logic from intake to final decision.\n\n## Visual & UI Guidelines\n- **Dashboard Layout**:\n    - **Sidebar**: Reserved for demo controls (Scenario selection, Latency toggle, Applicant ID).\n    - **Main Feed**: A prominent, real-time chat/trace area showing agent interactions.\n    - **Audit Panel**: A secondary area for live JSON logs to demonstrate compliance.\n- **Signaling**:\n    - Use standard iconography for agent personas:\n        - 🤖 **Loan Manager** (Orchestration)\n        - 🔍 **Investigator** (Data Gathering)\n        - 📜 **Policy Expert** (Compliance/RAG)\n        - ⚖️ **Underwriter** (Decisioning)\n- **Outcome Visualization**:\n    - Final decisions (APPROVE, DENY, ESCALATE) must be presented in high-contrast status boxes with clear, crisp justifications.\n\n## Communication Style (Prose)\n- **Crisp & Efficient**: Agent responses should be professional and direct. Avoid unnecessary preamble.\n    - *Example*: "Investigation complete. Identity verified. High DTI (45%) detected against policy threshold (43%). Proceeding to Policy Review."\n- **Fact-Based**: Every claim made by the agent must be grounded in either the retrieved data or the policy documents.\n\n## Presentation Logic\n- **The \"Trace\" is the Star**: The demo should highlight the parallel execution of tools (Credit + Employment + Fraud) to prove technical sophistication.\n- **Escalation Narrative**: For complex cases, the agent should clearly articulate *why* it is escalating, showing the audience that the system knows its own limits.
