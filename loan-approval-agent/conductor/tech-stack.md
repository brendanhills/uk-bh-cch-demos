# Technology Stack: Loan Approval Agent\n\n## Core Language & Runtime\n- **Python 3.12+**: The primary programming language, chosen for its mature AI/ML ecosystem and support for asynchronous operations.\n- **uv**: Dependency manager and project runner, ensuring fast, reproducible builds and isolated environments.\n\n## AI & Agent Orchestration\n- **Google Cloud Agent Development Kit (ADK)**: The framework used to define agent personas, tools, and the hierarchical orchestration logic.\n- **Vertex AI (Gemini 2.5/3)**: The underlying Large Language Models providing the reasoning, multimodal analysis, and natural language capabilities.\n- **RAG (Retrieval Augmented Generation)**: Local PDF processing (via `pypdf`) combined with ADK tools to ground agent decisions in internal policy documents.\n\n## Frontend & Presentation\n- **Streamlit**: Used to build the interactive demo dashboard, providing real-time visualization of agent traces and audit logs.\n\n## Security & Compliance\n- **Google Cloud DLP**: Used to identify and redact PII (Personally Identifiable Information) within logs and agent context.\n- **Real ID Tokenization**: A custom internal system for replacing sensitive government IDs with secure tokens during the underwriting process.\n\n## Utility & Decision Export\n- **fpdf / reportlab**: Libraries used for the automated generation of formal Decision Record PDFs.\n- **python-dotenv**: For secure management of environment variables and configuration.\n\n## Quality Assurance\n- **pytest**: The primary testing framework.\n- **pytest-asyncio**: For testing asynchronous agent workflows and tool calls.\n- **pytest-depends / pytest-ordering**: Used to manage complex integration test sequences.
