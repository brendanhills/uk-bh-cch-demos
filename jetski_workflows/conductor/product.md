# Product: Conductor for Jetski

## Project Principles

- **Replicate the powers of the Conductor gemini_cli extension for Jetski.**
  - Reference: https://github.com/gemini-cli-extensions/conductor
- **Distinct Roles: Project Task vs Workflow Execution**
  - Be very clear about whether you are editing Conductor files as a project task (building the tool) OR reading Conductor files as part of your workflow (tracking progress).
