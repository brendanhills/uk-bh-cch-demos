# Tech Stack: TDA Support & Data Generation

## Programming Language
- **Python:** Used for data generation scripts and automation.

## Core Libraries
- **ReportLab:** Primary library for generating high-fidelity synthetic PDF documents.
- **Pathlib:** For robust filesystem path management.
- **Datetime:** For managing dates in synthetic document generation.

## Google Cloud & Workspace Integration
- **Google Drive:** Storage for the generated synthetic documents.
- **Google Cloud Storage (GCS):** Alternative storage and ingestion point for agents.
- **BigQuery:** For storing and querying structured chargeback and log data (CSVs).
- **Gemini Enterprise:** The platform for building SME agents (via Agent Designer).
- **NotebookLM:** Used as a domain-specific "brain" for ingesting documents.

## Development Tools
- **Conductor:** Used for project management and development workflow orchestration.
