# Track Specification: ADK 2.0 Multi-Agent Concierge Workflow

## Overview
Transform the Cymbal Children's Hospital (CCH) concierge assistant into a modular, multi-agent system powered by Google Agent Development Kit (ADK) 2.0. Rather than relying on a single monolithic prompt, a master **Concierge Router Agent** dispatches specialized tasks to dedicated sub-agents:

1. **Patient Verification & Contact Agent** (`patient_verifier`): Validates patient name, Australian phone number formats (`04xx xxx xxx`, `02/03/07/08` area codes) (#BUG-46).
2. **Document Scanner & Vision Agent** (`document_scanner`): Handles document inspection requests, triggers camera scan function calls (#BUG-48 integration), and persists raw captured document snapshots to `app/logs/attachments/<session_id>_<timestamp>.jpg` (#BUG-45).
3. **Scheduling & EMR Specialist Agent** (`visit_scheduler`): Checks appointment availability, accurately maps practitioner selections (#BUG-29), books visits, and updates EMR records.
4. **Clinical SOAP & Transcript Export Agent** (`soap_generator`): Generates structured clinical SOAP (Subjective, Objective, Assessment, Plan) notes and handles session export endpoints (`/api/session/soap_note`) (#BUG-23).
5. **Web Search Grounding Tool** (`google_search_agent`): Integrated search tool for real-time web lookups (#BUG-25).

---

## Key Functional Requirements

### 1. ADK 2.0 Router & Sub-Agent Architecture (#BUG-43)
- Upgrade agent definitions in `app/cch_agent/` to ADK 2.0 sub-agent delegation (`LlmAgent` composition using `AgentTool` sub-agent tools or multi-agent runner dispatch).
- Root router agent `cch_concierge_router` directs user turns to domain sub-agents based on conversation context.

### 2. Australian Phone Number Validation (#BUG-46)
- System instructions and state validators in `patient_verifier` accurately recognize Australian mobile (`04xx xxx xxx`, `+61 4xx xxx xxx`) and landline (`02`, `03`, `07`, `08`) phone numbers.

### 3. Document Snapshot Persistence & Audit Trail (#BUG-45)
- When a document photo is captured, save raw JPEG bytes to `app/logs/attachments/<session_id>_<timestamp>.jpg` and log the saved path in `app/logs/transcripts/call_transcripts.log`.

### 4. Clinical SOAP Note Export Modal & Endpoint (#BUG-23)
- Implement FastAPI endpoint `@app.post("/api/session/soap_note")` generating clinical SOAP notes from call transcripts.
- Add `📄 SOAP Note` button and `#soapModal` dialog in UI with print and clipboard copy functionality.

### 5. Google Search Grounding (#BUG-25)
- Equip agent runner / router with `google_search` tool for background lookups when requested.

## Out of Scope
- Camera viewfinder UI controls (#BUG-48 camera auto-trigger UI remains in track `document_scanner_and_auto_trigger_20260805`).
- PII redaction / Google Model Armor integration (#BUG-38, future track).

## Acceptance Criteria
- [ ] Root `cch_concierge_router` agent seamlessly delegates across `patient_verifier`, `document_scanner`, `visit_scheduler`, and `soap_generator` sub-agents.
- [ ] Australian phone numbers are recognized and formatted correctly during initial patient check.
- [ ] Captured document images are saved to `app/logs/attachments/` and logged in `call_transcripts.log`.
- [ ] Clicking `📄 SOAP Note` in UI opens a modal displaying formatted SOAP note generated by `/api/session/soap_note`.
- [ ] All automated unit tests (`uv run python -m pytest`) pass cleanly.
